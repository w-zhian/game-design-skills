# GameRes 战斗数值模型与反馈设计

蒸馏自 GameRes 游戏策划版块高分老文（评分依据见
`skills/article-curation/references/curation-criteria.md`），涵盖战斗力建模、
伤害公式体系化设计流程、打击感反馈清单。

## 1. 战斗力计算模型

来源：《如何高效设计游戏——关于战斗力计算方式的总结》（Einsphoton/任江枫，
2014，https://www.gameres.com/forum/t/252735 ，82k 浏览，精华帖）

### 1.1 因式模型（内部平衡用）

- 纯 HP×ATK 对砍：胜负由 HP×ATK 决定，定义其为战斗力；战斗过程 = 双方
  战斗力相减，剩余战斗力 ÷ 胜方 ATK = 剩余 HP（可直接跳过逐回合模拟）。
- 引入速度：战斗力 = HP×ATK×SPD（SPD 为单位时间行动次数/频率）。
- 引入防御：战斗力变为**相对值**（受对方攻防差影响）。三单位战斗力可能
  出现 A>B、B>C 但 C>A 的非传递现象（石头剪刀布式克制）；攻防差拉得越大，
  该现象越少。
- 塔防对称模型：塔战斗力 = ATK×FRQ×RGE，敌战斗力 = HP×SPD，两边相等即
  "刚好击杀"；多塔对单敌可加法叠加，多塔对多敌需考虑抬手效应与队列间隔。
- 建议：因式模型用于战斗平衡调整与数值规划；面向玩家的战力展示用加权
  多项式（直观、数值小、增幅小），两者分工。

### 1.2 数值规划的价值观（同文）

- 反对把数值表格全关联自动化：会抹掉角色差异性、关卡兴奋感，产出线性单一，
  最后处处"微调"到面目全非。
- 好的数值规划 = 易读（给别人看）+ 只起规划参考作用而非硬性标尺。

## 2. 回合制伤害公式 11 步设计流程

来源：《如何做好回合制游戏的战斗体验？战斗数值公式设计详解》（灿洲，2019，
https://www.gameres.com/forum/t/853720 ，16k 浏览）

流程：公式类型 → 二级属性 → 一级属性 → 职业 → 二级属性公式 → 三级属性 →
技能属性 → 技能效果 → 计算步骤 → 最终公式 → 技能。要点：

1. **三大公式类型**：减法 (攻-防)×系数（梦幻/神武/问道）；除法
   攻/(攻+防)×系数（天龙）；乘法 攻×(1-免伤率)（大话，无防御属性）。
   立项之初定死，中途更换至少延 1-3 个月。
2. **公式变种两原则**：初期不要过于复杂（便于理解与扩展）；公式要稳定
   （100% 覆盖各种情况，如破甲 100% 时强制护甲为 0）。
3. 卡牌类可取消防御直接 攻×系数，把培养点集中到系数上：
   `(A-B)*(C+D+E)` 优于 `(A-(B+D))*(C+E)`。
4. **属性分级**：二级属性（攻防速/HP/MP）直接影响结果；三级属性（命中、
   闪避、暴击、免暴、封印、抗性等）间接影响——三级属性要设上下限（如
   闪避≤80%、命中率≥20%），并用"效果抵消"思路配对投放（装备加暴击就
   同时投免暴）。
5. **一级属性设计规则**：速度不要只受敏捷影响（否则敏捷加点收益过低），
   推荐敏捷系数为其他属性的 5-9 倍。
6. **系数定法**：模拟加点把二级属性化为等级线性式 → 设理想对战回合数
   （如 7 回合：HP/(攻-防)=7）→ 设平衡等级（玩家 N 个月达成的等级，如
   100）→ Excel 拉表定 A/B 值。A 值管加点收益、B 值管等级收益，
   同效果下 A+1 应强于 B+1。
7. **加成连加、衰弱连乘**：
   `攻×(1+a1+a2+a3)×(1-b1)×(1-b2)×(1-b3)`——加成连乘会爆到预设上限之外，
   衰弱连加会迅速归零。
8. 回合阶段概念（回合开始前/开始后/结束前/结束后/指令下达期）决定 dot、
   回复、复活的触发顺序；一般先回复再 dot，复活放最后。
9. 群攻伤害系数=1 应放在人数 1-2 上，否则群攻收益下降；暴击伤害加成
   回合制常用 1.5、卡牌常用 2；乱敏系数常用 90%-110%。

## 3. 打击感反馈清单

来源：《游戏开发经验分享：我所理解的打击感》（wjlpld，2015，
https://www.gameres.com/forum/t/384281 ，53k 浏览，精华帖）

两派路线：高端局（动作主导，动作贡献 80%+ 打击感，烧钱）与低端局
（特效主导，动作是特效的补充，性价比高）。

高端局（动作主导）要素：

1. 重量感：轻重武器的预备/挥动/收手差异必须一眼可辨。
2. 动作优美夸张且符合规律（需要"武术指导"式打磨）。
3. **受击动作是核心**：为每种攻击方向/轻重击/挑空/空中/背后配置对应受击，
   受击动作数量决定"拳拳到肉"程度。
4. 阻力感：命中时武器顿挫（有护甲时阻滞、破甲后流畅的反差带来爽快）。
5. 摄像机四件套：震动、放大缩小、慢镜头（子弹时间）、镜头特效（溅血/
   径向模糊）。
6. 断肢/死亡特效：怪物死亡必须华丽或复杂。
7. 场景破坏/碎片化：满足玩家撕碎一切的本能快感。
8. 音效音乐：不可分割，缺音效打击感大打折扣。
9. 难度：小怪 AI 不能是木头，挑战本身是乐趣来源。
10. 弹刀、闪避/反击、浮空连招等进阶机制。

低端局（特效主导）要点：

- 特效范围合理、配色贴合风格、表现夸张、细节特效（跑动/跳跃/倒地/出场）
  不省略。
- 连击数要醒目且增长有表现力，可适当放宽连击衔接窗口减少断连。
- 伤害数字是 UI 中最常被看的部分，暴击用独立一套扎眼数字。
- Boss 多段血条：一刀掉大半管（多管叠加），输出爽感远超单管血。
- 屏幕震动四窍门：方向跟随技能方向；幅度随伤害量；UI 不跟着震；按技能
  调震动延时。

## 使用建议

- 战斗数值规划：先用因式模型验证平衡与克制关系，再决定伤害公式类型与
  变种，最后按 11 步流程落地。
- 合成/割草类轻操作项目：优先低端局清单（数字、多段血条、屏幕震动、
  击杀碎片化），性价比最高。
