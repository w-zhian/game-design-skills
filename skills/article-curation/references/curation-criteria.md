# Curation Criteria (筛选与评分标准)

两套标准分工：

- **新文章摘录（每日增量）**：只看方向相关性 + 内容深度 + 文章结构，
  不看浏览量（第 1/2/3 节），满足即收录，不设流量门槛。
- **历史档案回顾（老文索引）**：额外叠加社区验证与综合分排序（第 5 节）。

## 1. 方向相关性（0-4 分）

| 分数 | 判定 |
| --- | --- |
| 4 | 标题/内容直击四大方向之一：系统设计、战斗设计、关卡设计、数值模块设计 |
| 3 | 明确属于游戏设计范畴，方向可推断（如"养成"、"商业化"中含数值/系统论述） |
| 2 | 泛策划话题（项目管理、入行经验、设计感悟），有方法论成分 |
| 1 | 文案/剧情/叙事类（仅当深度极高时保留，见第 4 条） |
| 0 | 招聘/广告/闲聊/纯求助/无观点转载 → 直接排除 |

方向关键词参考：

- 系统：系统, 模块, 框架, 拆解, 养成, 装备, 背包, 任务, 社交, 公会, 经济循环
- 战斗：战斗, 伤害, 技能, Boss, 职业, 打击感, 连招, 判定, AI, 仇恨, TTK
- 关卡：关卡, 副本, 地图, 难度曲线, 节奏, 引导, 心流, 解谜, 波次
- 数值：数值, 公式, 曲线, 成长, 产出消耗, 概率, 保底, 抽卡, 平衡, 通胀, DPS

## 2. 内容深度信号（0-3 分）

标题与列表元信息即可判断大部分信号：

- 含"干货/深度/复盘/总结/框架/方法论/专题/万字/长文"等词：+2
- 置顶帖、精华帖：+2
- 标题提出具体机制问题并暗示有论证过程：+1
- 标题纯情绪化/标题党/无信息量：+0

## 3. 文章结构检验（新文摘录的必要条件）

新帖发布初期没有流量积累，**不以浏览/回复数设门槛**，改为精读正文时
检验结构与深度，两者都达标即收录：

- 结构达标：有明确论点与展开（分节/分点/小标题/案例对照/推导步骤），
  而非纯情绪吐槽、碎碎念或无观点转载。
- 深度达标：至少包含以下之一——可复用框架/公式/模板；带数据或案例
  的论证；反例/踩坑经验；与主流观点的对比分析。
- 两者缺一：降入"落选但值得留意"；纯水文直接排除。

（浏览/回复数仅在历史档案回顾时计分：>=1000 或回复>=20 记 +2，
>=300 或回复>=5 记 +1，代表长期社区验证。）

## 4. 文案类特例

文案/剧情/叙事方向默认 LOW。仅当同时满足以下条件才收录：

- 相关性 >= 1 且深度信号 >= 2
- 内容包含可复用的结构方法（如叙事框架、剧情节奏模板），而非纯创作展示

## 5. 多维排序（综合分）

候选超额时按综合分排序，浏览量仅作同分决胜，不主导排序：

```
综合分 = 内容评分 + 精华加2 + 作者活跃等级 x 0.5
```

- **精华帖（is_essence）+2**：官方加精 = 专业性认证，最强信号。
- **作者活跃等级 L0-L5**：按版块内产出量定级（权重 = 发帖数 + 精华数x3；
  >=150→L5，>=60→L4，>=20→L3，>=6→L2，>=2→L1，否则 L0）。
  高活跃作者的内容稳定性与专业度显著更高（如 sea_bug、小篱、Chengsoul）。
- 同综合分时：发布时间更近者优先。
- 精读名额上限 5 篇；落选但总分 >= 5 的进入"落选但值得留意"。

## 6. 摘要提取要点

精读正文时按此优先级提取：

1. 可复用的框架/模型/公式（保留原始术语与数字）
2. 结论性观点及其论据
3. 作者给出的反例/踩坑经验
4. 与其他文章观点的冲突或呼应（若能识别）

避免：摘抄大段原文、营销话术、与四大方向无关的延伸。
