# GameRes 概率与变化建模方法

蒸馏自 GameRes 游戏策划版块高分老文（评分依据见
`skills/article-curation/references/curation-criteria.md`），用于概率期望计算、
伪随机分布设计与成长/经济的变化建模。

## 1. 概率期望的两种通用计算方法

来源：《数值策划纯干货：游戏概率计算的通用方法》（破戒僧，2016，
https://www.gameres.com/forum/t/490320 ，38k 浏览）

核心思想：概率计算思考角度不同会得出天差地别的结果（强化期望次数不同算法
可差数百上千倍），优先用借助计算机的通用方法，少用纯公式。

### 1.1 循环模拟法

- 用随机数模拟每次事件结果，累加计数，百万次模拟后取平均。
- 优点：简单粗暴、几乎不需要数学公式、不易出错；适合做公式结果的验算。
- 把"需要凑齐的部件数量"做成函数参数，条件变化时不用改循环主体。

### 1.2 函数递归法（期望递推）

核心依据期望定义：**期望次数 = 各分支（1 + 剩余期望次数）× 分支概率 的加权和**。

- 双部件互斥掉落（pa/pb）集齐期望：
  `x = 1 + pa*(1/pb) + pb*(1/pa) + (1-pa-pb)*x`
  （第一次掉 a 则还差 1/pb 次，掉 b 则还差 1/pa 次，都不掉还需 x 次）
- 多部件收集递推：`n[A,B,C] = 1 + Pa*n[A-1,B,C] + Pb*n[A,B-1,C] + Pc*n[A,B,C-1]`
  边界：`n[nA,0,0] = nA/Pa`；两类混合时如
  `n[nA,nB,0] = (1 + Pa*n[nA-1,nB,0] + Pb*n[nA,nB-1,0]) / (1-Pc)`
- 直觉校验法：条件更苛刻的期望必然更大（"至少看到一次正面和一次反面"必然
  大于 2 次，因为只看到其中一面平均就要 2 次）。

## 2. 统计概率 vs 分布概率（伪随机设计）

来源：《抽卡艺术：深度分析游戏中随机概率》（HuangWei，2015，
https://www.gameres.com/forum/t/466473 ，45k 浏览）

**关键区分**：5% 概率 ≠ 20 次出现一次。

- 直接随机（权值法）只满足统计意义上的 5%，实际间隔呈下坡分布，可能连续
  出现也可能 160 次不出——玩家吐槽"脸黑"的根源。
- 列表洗牌法（1 个目标 + 19 个填充，shuffle 后依次取）可保证"20 次出现一次"，
  间隔均匀分布在 20 附近；权值需先约分（GCD），多物品且 GCD=1 时不可行，
  且列表内存开销大。
- **推荐做法：正态分布伪随机**。以周期 T=1/p 为均值，取 μ=T、σ=T/3
  （3σ 覆盖 99%），按正态分布生成每个物品的下次出现间隔，取最小值者产出，
  其余间隔减去该值（可优化为对被取者加增量，O(N)→O(1)，配合最小堆）。
- 计数器保底法（累加概率≥1 必出）效果等价，但每玩家每库每物品都要存一个
  计数器，空间代价大。
- 随机种子：非全服竞争资源（抽卡、关卡掉落）应每玩家独立种子；全局共享的
  正态随机序列被不同玩家截取片段后，各自序列不再服从目标分布。

## 3. 变化与导数：数值体验的量化视角

来源：《为什么微分方程是数值策划工作的主要方法论？》（巴比伦人/Chengsoul，
2023，https://www.gameres.com/forum/t/901937 ，14k 浏览）

核心观点：玩家更容易感知的是**变化**而非绝对值，导数比存量更准确地描述体验。

可映射的导数实例：

- 角色成长（等级/攻击随时间变化）= 属性对时间的一阶导；系统按等级开放 +
  体力限制每日次数，是在操控这条曲线的形状。
- 模拟经营的利润 = 收入对时间的一阶导；员工/设施提升利润增速 = 二阶导。
- 付费成长 = 属性对付费金额的一阶导；VIP 每日额外产出使资源获取的二阶导
  为正，免费玩家二阶导为 0——付费深度的量化表达。
- 留存、流水、销售额的升降判断本质都是看对时间的一阶导。

设计启示：

- "做数值就是做体验"的落实方式 = 找到变化 → 写出变化的方程 → 用边界/初始
  条件描述系统特点；在残差平方和指标下，微分方程建模优于一次/二次代数拟合。
- 差分方程是微分方程的离散形式（步长恒为 1 的前向差分），日常拉表本质上
  就在用差分思维。

## 使用建议

- 涉及强化/合成/收集类期望次数：先写递归方程求精确解，再用循环模拟验算。
- 涉及掉落/抽卡体验：区分"统计达标"与"分布合理"，优先正态伪随机或保底计数。
- 设计成长/付费曲线时，先回答"一阶导（成长速度）和二阶导（增速变化）长什么样"，
  再落表。
