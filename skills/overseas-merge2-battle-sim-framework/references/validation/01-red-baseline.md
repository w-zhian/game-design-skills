# Merge-2 战斗 Skill v1：RED 基线

## 方法与结论

本基线只按 `02-test-prompts.md` 的五个固定 Prompt 和 v1 Skill 运行。摘录是依照 v1 明示的路线定义、输出协议与 Kill Criteria 模板生成的最短回答摘要；评分不把测试者事后补充的字段计入。下文的 `SKILL.md` 均指 v1 包相对路径 `overseas-merge2-battle-sim-framework/SKILL.md`。

结果：**RED 确认**。P1—P5 均有至少一个必需字段为 0。失败来自 v1 的通用框架在这些精确交付字段上没有足够的固定输出约束，不是虚构失败。

## 逐 Prompt 原始回答摘要与评分依据

### P1 A 路线 60 秒夜间防守：不通过

**来源：** `SKILL.md` → “三条产品路线 / A《Last Light Motel》”；`SKILL.md` → “快速评审清单 / 循环”；`SKILL.md` → “量化 Kill Criteria 模板”。

**v1 摘要：** “每日一次 45—90 秒三入口自动防守，战前准备 + 两次轻干预；结果回写维修、营救、治疗、庆祝和人物冲突。”这直接支持战前选择（2）、玩家干预（2）、失败回写（2）。但它没有把请求的 60 秒分段，也没有给出该局的验证指标、窗口或阈值，因此时间分段（0）、验证指标（0）。可观察因果只有“战斗检验可观察的准备选择”的原则，未逐项连接本局准备与结果，记（1）。

评分：战前选择 2；时间分段 0；玩家干预 2；可观察因果 1；失败回写 2；验证指标 0。

### P2 武器链跨入战斗：不通过

**来源：** `SKILL.md` → “三环分析”；“七个核心心智模型 / 三环齿轮，而非三层蛋糕”；“十条决策启发式 / 单系统对象删除测试、胜负解释测试”；“快速评审清单 / 循环”。

**v1 摘要：** “Merge 产物是否直接进入经营或战斗”“如果只能说战力不足，增加装载、站位、设施或路线决策”“结果返回棋盘、世界或角色。”这支持战斗对象（2）和局后回写（2）的框架性回答。v1 没有要求为一条武器链固定棋盘身份/层级、部署触发时机，或空间目标规则，均只能部分回答（1）。它也没有可执行的‘何时退化成战力加成’判定，记（0）。

评分：合成物身份 1；战斗对象 2；触发时机 1；空间/目标差异 1；局后回写 2；降级判定 0。

### P3 B/C 同敌异构：不通过

**来源：** `SKILL.md` → “三条产品路线 / B《Mythic Caravan》、C《Dustbound Convoy》”；`SKILL.md` → “七个核心心智模型 / 风险必须放大所有权”。

**v1 摘要：** B 的核心是“伙伴、图鉴、移动商队”，战斗为“三宠自动执行、战前站位、一件器具、一次主动指令”，回写“生态钥匙、谱系、蓝图和新订单”。该路线条目未列出 B 自身的压力源或战斗失败结果，故两项不能补造。C 的核心是“车辆、货物、幸存者”，主情绪为“资源永远不够”，战斗为“自动追逐，换道、标记目标、一次技能”，回写“货损、伤员、绕路、维修、残骸和关系”。C 的回写可表明受损后果，但未明说这是失败结果，故只记部分。

评分：B 所有权 2；B 压力源 0；B 干预 2；B 失败结果 0；B 回写 2；C 所有权 2；C 压力源 2；C 干预 2；C 失败结果 1；C 回写 2；不可共用机制 2（宠物站位/器具 vs 车队换道/标记）；非换皮因果 2（生态/谱系订单 vs 货损/维修绕路）。

### P4 浪漫餐厅反例：不通过

**来源：** `SKILL.md` → “无战斗与灾害替代”；“回答工作流 / Step 2：框架式研究 / 产品结构”。

**v1 摘要：** “灾害结算可以承担战斗的系统功能；若玩家不与敌人对抗，需把战斗重命名为风险/灾害结算，并证明灾害不是纯数值扣除。”这支持‘不把经营阻塞当战斗’的直接判断（2）。但对浪漫餐厅，它没有一张显式的相邻品类基准/可借鉴/不可类推矩阵：品类关系、剧情经营基准和可借鉴层只能部分回答（各 1），不可类推层为（0）。

评分：品类关系 1；Merge-2 剧情经营基准 1；是否有战斗 2；可借鉴层 1；不可类推层 0。

### P5 无项目数据的 TTK 曲线：不通过

**来源：** `SKILL.md` → “输入收敛与追问上限”；“回答工作流 / Step 4：输出”；“量化 Kill Criteria 模板”；“七个核心心智模型 / 证据阶梯决定投资阶梯”。

**v1 摘要：** “不凭空给 CPI、留存、LTV、产能或收入阈值；没有可靠基准时，给测量方法和阈值设定方式”，并要求首次出现时标记“事实/推断/待验证假设”。它提供包含主指标、护栏、窗口、通过/否决阈值和未通过动作的通用 Kill Criteria 模板。因此证据标注（2）、Kill Criteria（2）。但 v1 没有定义无量纲 TTK/压力口径，也没有三阶段的曲线目标，二者为（0）；原型测量到遥测替换只可从“最小验证”推导，记（1）。

评分：证据标注 2；归一化指标 0；阶段目标 0；替换实测的方法 1；Kill Criteria 2。
