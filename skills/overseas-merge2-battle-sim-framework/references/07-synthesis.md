# 海外二合战斗模拟经营：框架提炼

调研时间：2026-07-24。  
输入：7 份调研文件、79 个不重复 URL，覆盖官方商店与产品材料、平台/监管政策、数据商报告、行业拆解和用户定性反馈。  
性质：主题 Skill，不模拟任何单一人物；采用中性、结论先行、证据与推断分离的产品决策语言。

## 一、领域共识

跨叙事 Merge、收藏养成、模拟经营、混合策略与车队生存流派，可确认以下共识：

1. Merge-2 的价值不是“升级图标”，而是把复杂系统压缩成易读的短动作。
2. 模拟经营只有在改变生产、路线、角色或风险时才是经营；纯百分比升级只是 Meta 进度。
3. 战斗只有在检验合成和经营选择时才属于同一产品；独立战力系统会吞噬 Merge 身份。
4. 高收入产品依赖持续 LiveOps、Offer 与内容复用，不依赖一套静态主循环永久运转。
5. 低门槛入口可以承接深 Meta，但广告、首日体验和长期核心的承诺必须一致。
6. 新产品不能直接复制头部产品已经积累数年的内容库、联盟生态与运营密度。

## 二、核心心智模型（7 个）

### 模型 1：三环齿轮，而非三层蛋糕

**一句话：** Merge、经营、战斗必须互相改变下一环输入；只把三套玩法叠在菜单中，等于承担三份成本而没有融合。

**跨域证据：**

- A：合成灯具、药品与路障 → 改变夜防 → 战损生成次日修复和营救订单。
- B：合成器具、食物与谱系记忆 → 改变远征队 → 远征带回生态钥匙并重构商队生产。
- C：合成武器、装甲、补给与雷达 → 装入车厢 → 路线战损与残骸改变下一轮装车。

**生成力：** 面对任何新功能，先问它改变哪个系统的输入。如果只产生孤立货币、独立体力或独立战力，默认删除或重接。

**排他性：** 常见混合产品以“轻玩法获客、重系统变现”为目标，允许入口逐渐被雪藏。本框架要求获客玩法长期常驻，并对 Meta 继续有决定性作用。

**局限：** 过度追求每个对象跨三系统会让规则难懂。首周只要求一条清楚因果链；边缘内容可以只服务一至两个系统。

### 模型 2：承诺守恒

**一句话：** 玩家从广告中购买的是一个心理契约；产品复杂度可以增长，但不能把最初承诺替换掉。

**跨域证据：**

- A 的真实承诺是“白天修家、晚上守家”，而不是只在广告中救一个受难角色。
- B 的真实承诺是“我合成的东西让伙伴改变战局”，而不是广告两次进化、游戏内数周抽卡。
- C 的真实承诺是“装车、选路、追逐战”，而不是五分钟后退化成固定基地计时器。
- ASA 的多次指引和裁决表明，“玩法确实存在”也不等于广告能代表核心体验。

**生成力：** 每条规模化素材必须对应一个首会话可玩、首周可重复、长期不被 sunset 的机制。

**排他性：** 不把虚构 mini-game 当作可接受的低 CPI 手段；把创意真实性视为产品 KPI。

**局限：** 广告允许戏剧化、压缩时间和强化表现。守恒的是主要交互与因果，不是要求素材逐帧等于客户端。

### 模型 3：风险必须放大所有权

**一句话：** 战斗的作用不是给产品增加刺激，而是让玩家更在乎自己经营的人、伙伴和车队。

**跨域证据：**

- A：夜防让暖窗、房间和居民从装修对象变成“值得保护的家”。
- B：远征让伙伴性格、设施选择与补给准备获得可观察的价值。
- C：路线战让车厢布局、幸存者岗位和货物优先级成为有后果的选择。

**生成力：** 设计失败结果时，优先生成修复、撤退、情报、关系和下一次选择，不先摧毁付费资产或永久删除角色。

**排他性：** 不是用更重惩罚证明战斗有意义，而是用可追溯的后果证明准备有意义。

**局限：** 若所有失败都自动转成奖励剧情，风险会失去可信度。仍需存在机会成本、资源损耗、路线放弃或暂时伤势。

### 模型 4：约束产生经营

**一句话：** 经营的本质是不能同时拥有全部最优解；空间、时间、情报和照料对象必须迫使玩家排序。

**跨域证据：**

- A：生活、维修、人物、防务订单争夺同一棋盘产能。
- B：孵化室、厨房、工坊、温室、地图室受商队容量限制。
- C：高阶物品更强，但装车格有限；玩家必须决定“现在装车还是继续合”。

**生成力：** 每个设施、订单和库存扩展都要回答：玩家牺牲了什么？若没有牺牲，只是线性升级。

**排他性：** 不把模拟经营理解成“等待计时器结束后升级所有建筑”。

**局限：** 约束过多会变成持续堵塞。必须提供预览、撤销、换单、拆解、仓库与补救路径。

### 模型 5：一份资产，多重语义

**一句话：** 内容可持续的前提是同一对象同时承担玩法、叙事、经营和商业价值。

**跨域证据：**

- A 的居民、房间与灾害可以同时产生订单、夜战岗位、剧情、装饰和活动。
- B 的魔宠可以同时是收藏对象、生产单位、战斗单位、叙事角色和外观载体。
- C 的车辆与幸存者可以同时定义棋盘生成器、车厢格、战斗角色、路线能力与广告形象。
- 头部 Merge 和 4X 的高 LiveOps 密度说明单系统专用内容难以长期承受。

**生成力：** 新增一个对象前，要求至少两个系统使用同一资产；新赛季尽量用一个主题覆盖棋盘、场景、敌人、剧情和商品。

**排他性：** 不用“每个系统各自精彩”作为设计目标，而以单位内容的跨系统产出为目标。

**局限：** 过度复用会让世界显得廉价。核心角色、Boss、关键房间和赛季高潮仍需独占内容。

### 模型 6：LiveOps 是产品架构，不是上线后加活动

**一句话：** 主循环必须从第一天就能承载事件；否则每次活动都会复制棋盘、经济、UI 和内容团队。

**跨域证据：**

- Merge 头部收入越来越来自活动 Offer、通行证、特殊棋盘、收藏与排行榜。
- Strategy 头部依靠日常重复、功能活动和联盟/赛季大事件的多层节奏。
- A/B/C 都能用一个灾害/生态/路线主题同时驱动订单、战斗、经营和商业化。

**生成力：** 一周一个主主题，三个系统共用一张奖励地图；首年遵守“3 个常驻核心货币 + 最多 2 个同时可见活动代币”。

**排他性：** 不把“活动多”误认为 LiveOps 成熟；成熟标准是内容复用、配置工具和可持续产能。

**局限：** 过度模板化会造成重复疲劳。建议 70% 参数/主题替换、20% 新内容、10% 新系统，并用数据调整比例。

### 模型 7：证据阶梯决定投资阶梯

**一句话：** 不用头部竞品收入证明自己的产品；每一层投资必须由上一层的可证伪证据解锁。

**跨域证据：**

- A 的核心未知是 Cozy 用户是否接受每日战斗，以及真实日夜素材是否改善获客质量。
- B 的核心未知是 Merge 用户与收藏/轻策略用户是否真实重叠，以及伙伴是否能在不依赖 Gacha 时商业成立。
- C 的核心未知是 PvE-first 是否已有 D7/D30 价值，还是必须依赖完整 4X 才能成立。
- 市场报告无法提供本项目的 CPI、留存、LTV 和内容工时。

**生成力：** 概念素材 → 20–30 分钟闭环 → 7 日纵向切片 → 8–12 周经济/LiveOps；每一步都有 Kill Criteria。

**排他性：** 不以“大品类正在增长”替代产品证据，也不在软启动前承诺完整世界战、每周新宠或高密度周更。

**局限：** 阶段验证可能低估强内容/IP 的长期价值；不能只用短期指标扼杀需要累积情感的设计，因此定量数据需与访谈和内容产能一起判断。

## 三、决策启发式（10 条）

1. **单系统对象删除测试**：如果一件物品只服务一个系统，先尝试删除或让它改变另一个系统输入。
2. **首周承诺测试**：如果广告中的主要操作不能在前 10 分钟出现、D0—D7 重复，就不规模化该素材。
3. **胜负解释测试**：如果战后只能说“战力不足”，增加可观察的装载、站位、设施或路线决策。
4. **经营取舍测试**：如果设施最终都能同时满配，加入容量、岗位、维护或路线机会成本。
5. **失败内容测试**：失败先生成修复、情报、关系或绕路；除非目标受众明确接受，不永久毁掉情感/付费资产。
6. **主题复用测试**：若一个新活动同时要求全新棋盘、物品链、角色、敌人和货币，默认缩减或拒绝。
7. **核心人群优先**：A 先保护照料感，B 先保护伙伴身份，C 先保护物流决策；不要为了“男女通吃”抹平主情绪。
8. **深度后置测试**：英雄池、实时 PvP、跨服与完整 Gacha 都必须由交叉参与率、LTV 和运营能力解锁。
9. **透明付费测试**：付费卖效率、选择宽度、收藏和表现；不把角色生命、道德选择或基础玩法入口直接标价。
10. **两周可生产测试**：概念若无法被既定团队按双周/月度节奏持续生产，就算原型好玩也不应直接立项。

## 四、三条路线的根本分歧

| 维度 | A 温馨末日社区 | B 魔宠远征商队 | C 废土车队争霸 |
|---|---|---|---|
| 主情绪 | 在危机中照顾具体的人 | 发现、培育并带伙伴远行 | 在资源不足时做艰难取舍 |
| 核心所有权 | 家、居民、关系 | 伙伴、图鉴、商队 | 车队、货物、幸存者 |
| Merge 对象 | 食物、工具、药品、防务 | 蛋胚、食物、符文、模块 | 武器、装甲、补给、情报 |
| 战斗作用 | 每日经营成果验收 | 伙伴/器具组合的展示 | 装车与路线选择的压力测试 |
| 失败形态 | 修复、营救、关系剧情 | 疲劳、撤退、保留情报 | 货损、伤员、绕路、维修 |
| 商业上限 | 中高，靠剧情/活动/装饰 | 高，靠收藏/外观/赛季 | 最高，靠成长/联盟/赛季 |
| 最大成本 | 周更叙事与活动 | 角色美术、动画与平衡 | 服务器、联盟、数值与运营 |
| 首发禁区 | 英雄抽卡、重 PvP | 吞宠、完整角色 Gacha | 同步世界战、假玩法获客 |

## 五、表达 DNA

主题 Skill 激活后使用以下表达方式：

- 先给产品判断，再给因果链和证据。
- 明确标注“事实 / 推断 / 待验证假设”。
- 用 30 秒、单次会话、日、周、赛季五层时间尺度描述循环。
- 用“输入改变什么、结果回写哪里”检查系统关系。
- 每个建议同时写收益、代价、失效条件和 Kill Criteria。
- 不说“融合热门玩法”“全球化题材”“市场潜力巨大”等空泛结论。
- 不用竞品收入倒推本项目预算、留存或成功概率。
- 推荐默认克制：先做可证伪的最小纵向切片，再解锁重系统。

## 六、价值排序与反模式

### 价值排序

1. 产品承诺与真实玩法一致。
2. 三系统形成可读因果闭环。
3. 核心受众的主情绪不被商业化破坏。
4. 内容和运营产能可持续。
5. 深度、社交和付费上限逐级解锁。

### 反模式

- Merge 只生产经验材料。
- 经营只有百分比升级。
- 战斗只比综合战力。
- 广告玩法在中后期消失。
- 每个玩法拥有独立体力、货币、活动和通行证。
- 用完整 4X、每周新宠或周更长剧情掩盖闭环尚未成立。
- 把随机付费、儿童吸引力与真实价格披露留到上线前处理。

## 七、核心张力

1. **低门槛 vs 长线深度**：越容易理解，越可能缺乏中期选择；越早叠系统，越可能破坏入口。
2. **安全感 vs 风险**：危险让所有权变重，但过度惩罚会摧毁 Cozy 与角色依恋。
3. **个体身份 vs Merge 消耗**：对无人格物品，合并是满足；对已命名伙伴，合并可能被视为损失。
4. **高付费上限 vs 用户信任**：能量墙、随机池和联盟压力能变现，也最容易违背初始承诺。
5. **内容丰富 vs 生产可持续**：更多活动可以提高收入，但每个新系统都会增加永久运营负债。
6. **泛用户扩圈 vs 鲜明主情绪**：混合受众有价值，但不能用模糊定位换取表面覆盖。

## 八、诚实边界

- 所有市场收入、留存和受众画像均来自公开报告或第三方估算，不是竞品内部审计。
- 79 个不重复 URL 中存在跨文件重复引用；来源数量不等于独立结论数量。
- 本框架没有本项目真实 CPI、D1/D7/D30、LTV、付费分布、团队工时和技术预算。
- A 的女性画像、B 的跨人群交集、C 的男性主盘均是首发验证假设，不是保证。
- 无法仅凭概念判断哪条路线最终胜出；必须通过相同标准的素材、闭环和纵向切片测试。
- 合规内容只用于产品风险识别，不替代目标国家/地区的专业法律意见。
- 调研截止到 2026-07-24；市场、政策、竞品版本和广告生态会继续变化。
