# GameRes 关卡体验量化与玩家思维分析

蒸馏自 GameRes 游戏策划版块高分老文（评分依据见
`skills/article-curation/references/curation-criteria.md`），用于关卡数值框架
搭建与关卡乐趣结构分析。

## 1. 关卡战斗数值框架：把体验变成数据

来源：《做数值就是做体验！RPG游戏关卡数值设计思路分析》（华韬，2019，
https://www.gameres.com/forum/t/847350 ，77k 浏览）

核心命题：**做数值就是做体验**。"无聊"、"难"是主观词，必须拆成可计算维度。

### 1.1 四维度框架

1. **难度**：操作系数与战斗力要求如何动态调整并验算。
2. **战斗时间**：清小怪/打 Boss 各需多久。
3. **战斗节奏**：Boss 战的高潮低潮，玩家按 Boss 技能切换打法
   （策略型节奏=围绕探索/收集/降难度设计；操作型节奏=围绕 Boss 玩法设计）。
4. **操作数据**：完美操作损失多少血击杀 Boss；挂机操作损失多少血、能否击杀。

### 1.2 需求量化方法

把制作人/需求方的抽象描述逐条列成对照表再求解，两个好处：

- **暴露逻辑冲突**：如"普通玩家操作好能通关"与"需充值到 5000 战力才能过"
  同时出现，用抽象语言难发现，列成不等式（C 类玩家防御力 ≥/< Boss 要求
  防御力）立刻冲突可见。
- **定义数值边界**：所有设计在边界内进行，如"C 玩家操作好能通关" ⇒
  Boss 不可躲避技能伤害必然小于玩家总血量。

### 1.3 强制卡战力手法

"很难打 ≠ 打不过"：很难打强调操作，打不过强调战斗力。卡战力实现示例：
加"要求防御力"属性——敌方要求防御力 > 我方防御力时，我方伤害 -60%、
受击伤害 +200%。常用于卡付费层级。

## 2. 玩家思维关卡分析框架

来源：《【玩家思维】关卡分析与实践要点》（邪让多杰，2018，
https://www.gameres.com/forum/t/806539 ，71k 浏览）

以《星际争霸2》合作模式为范例的六问分析法：

1. **为什么进入关卡**：显性因子（奖励驱动，如升级）负责引导；隐性因子
   （排解无聊、追求动脑频率）才是长期驱动。关卡内容本身必须提供乐趣，
   否则奖励耗尽后玩家即流失。
2. **进入后获得什么**：动脑频率 = 持续的决策需求。手段：
   - 终极目标拆成阶段性目标小循环（"防守这一波"、"拿下这个点"），
     随时间复杂度递增，末段进入短时高频的紧张刺激。
   - 附加任务服务高水平玩家：同局内菜鸟做阶段目标、高手做附加任务，
     局部扩大用户范围。
3. **如何扩大玩家范围**：降低动脑频率门槛（英雄/自动采集等替玩家承担
   部分决策），让原本吃力的玩家也能获得乐趣。
4. **如何维护老玩家乐趣**：随等级解锁更多技能/策略树（策略的"阶段奖励"），
   满级后用高难度档位（如残酷难度）释放丰富策略，补偿被简化的决策频率。
   警惕：单套路即可通关的强势设计属于设计漏洞。
5. **如何降低挫败感**：多人/合作机制提供"猪队友背锅"空间，容错率提升、
   挫败归因外化；高难度游戏几乎必须配多人模式。
6. **如何延长所有玩家乐趣**：规则抽象替换（突变任务）——核心模式不变，
   每周叠加随机规则限定（"大型怪物死后变核弹"），强制玩家重新学习策略，
   以最高性价比制造新鲜感。前提是系统从设计之初就把规则抽象成可替换层。

## 使用建议

- 关卡立项：先用四维度框架把抽象需求列成量化对照表，检查冲突、定边界，
  再落怪物数值框架与关卡强度表。
- 关卡复盘/竞品分析：按六问逐一回答，定位乐趣来源与生命周期短板。
- 合成/割草类项目可直接借用：阶段性目标小循环、附加任务分层、周常
  突变规则（低成本延长寿命）。
